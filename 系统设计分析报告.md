# 智能笔记本系统 - 设计分析报告

## 一、用例分析

### 1.1 普通用户用例

| 模块 | 用例 | 描述 |
|------|------|------|
| **账号** | 注册 | 手机号+密码+验证码注册，系统随机生成用户名 |
| | 登录 | 手机号+密码+验证码登录，获取Token |
| | 登出 | 退出登录，清除session |
| | 个人信息 | 查看/编辑用户名、真实姓名、性别、出生日期 |
| **笔记** | 创建笔记 | 在指定笔记本下创建Markdown笔记 |
| | 查看笔记列表 | 分页查看笔记，支持按笔记本/关键词筛选 |
| | 查看笔记详情 | 查看完整笔记内容，含Markdown渲染 |
| | 编辑笔记 | 修改标题、内容、标签 |
| | 删除笔记 | 删除指定笔记 |
| | 置顶笔记 | 切换笔记置顶状态 |
| | 自动保存 | 编辑器自动保存内容 |
| | 管理标签 | 添加/删除笔记标签，查看所有标签 |
| | 搜索笔记 | 按标题/内容搜索 |
| | 添加到知识库 | 将笔记内容添加到个人知识库（向量化） |
| **笔记本** | 创建笔记本 | 创建分类笔记本 |
| | 查看笔记本 | 查看所有笔记本，含笔记数量统计 |
| | 编辑笔记本 | 修改名称、描述 |
| | 删除笔记本 | 删除笔记本（含下级笔记） |
| **文件管理** | 上传文档 | 上传 md/txt/doc/pdf → 自动转PDF → 向量化入库 |
| | 查看文件列表 | 分页查看，支持排序和搜索 |
| | 删除文件 | 删除文件及关联向量数据 |
| | 测试解析 | 测试文档解析功能 |
| **AI问答** | 流式聊天 | 发送消息，流式接收AI回复（带速率控制） |
| | 上下文记忆 | 基于memoryId的多轮对话 |
| | 用户增强 | 自动附加用户信息增强prompt |
| **知识库** | 创建知识库 | 创建共享知识库（名称/描述/封面/密码） |
| | 查看我的知识库 | 我创建的 + 我加入的 |
| | 知识库广场 | 浏览/搜索公开知识库 |
| | 加入知识库 | 输入密码（如有）加入 |
| | 退出知识库 | 退出已加入的知识库 |
| | 管理成员 | 创建者可移除成员 |
| | 上传文件 | 上传文档到共享知识库 |
| | 复制文件 | 从个人知识库复制文件到共享知识库 |
| | 删除文件 | 删除知识库中的文件 |
| | AI对话 | 基于知识库内容的AI问答 |

### 1.2 管理员用例

| 模块 | 用例 | 描述 |
|------|------|------|
| **仪表盘** | 查看统计数据 | 总用户数、启用/禁用用户、全局笔记数、全局笔记本数、知识库数、7日新增 |
| **用户管理** | 查看用户列表 | 分页查询，按角色/状态/关键词筛选 |
| | 查看用户详情 | 查看单个用户完整信息 |
| | 编辑用户 | 修改用户名、手机号、角色、状态 |
| | 禁用/启用用户 | 切换用户启用状态 |
| | 更改用户角色 | 升级为管理员 / 降级为普通用户 |
| | 删除用户 | 删除用户及其笔记、笔记本 |
| **知识库管理** | 查看所有知识库 | 分页查询，按状态/关键词筛选 |
| | 启用/禁用知识库 | 切换知识库状态 |
| | 删除知识库 | 删除知识库及成员、文件关联 |
| | 管理成员 | 查看成员列表、添加成员、移除成员 |

## 三、五大模块功能设计

### 3.1 用户管理模块

#### 3.1.1 模块概述
负责用户身份认证、授权、个人信息管理，以及管理员的用户管控功能。

#### 3.1.2 核心实体
| 表名 | 说明 | 关键字段 |
|------|------|----------|
| `t_user` | 用户表 | id, phone, password(SHA256), role_type(1=ADMIN/2=USER), username, avatar_url, real_name, gender, status(0=禁用/1=启用), last_login_time |

#### 3.1.3 认证流程
```
注册: phone + password + captcha → SHA256(password) → 随机中文名 → 插入t_user
登录: phone + password + captcha → SHA256验证 → 检查status → Sa-Token签发JWT → 存session(role, user_info)
授权: @SaCheckLogin(需登录) / @SaCheckRole("ADMIN")(需管理员) / @SaIgnore(公开)
路由守卫: router.beforeEach → 检查token → fetchUserInfo → 检查requiresAdmin
```

#### 3.1.4 API接口
| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| POST | /api/common/register | 公开 | 用户注册 |
| POST | /api/common/login | 公开 | 用户登录，返回Token |
| GET | /api/common/captcha | 公开 | 获取图形验证码 |
| POST | /api/common/logout | 登录 | 退出登录 |
| GET | /api/common/user/info | 登录 | 获取当前用户信息 |
| PUT | /api/common/user/update | 登录 | 更新个人信息 |
| GET | /api/admin/users | ADMIN | 分页用户列表 |
| GET | /api/admin/users/{id} | ADMIN | 用户详情 |
| PUT | /api/admin/users/{id}/status | ADMIN | 启用/禁用 |
| PUT | /api/admin/users/{id}/role | ADMIN | 更改角色 |
| PUT | /api/admin/users/{id} | ADMIN | 编辑用户 |
| DELETE | /api/admin/users/{id} | ADMIN | 删除用户 |

#### 3.1.5 安全设计
- 密码 SHA256 哈希存储，不与明文交互
- Sa-Token + JWT 无状态认证
- Redis 存储验证码，5分钟过期

- 管理员不允许删除其他管理员
- 前端路由守卫阻止非管理员访问 /admin

### 3.2 RAG智能问答模块

#### 3.2.1 模块概述
基于 LangChain4j + PostgreSQL pgvector 实现 RAG (检索增强生成)，支持流式输出和速率控制。

#### 3.2.2 核心组件
| 组件 | 技术 | 职责 |
|------|------|------|
| 向量存储 | PgVectorEmbeddingStore | 存储文档的向量嵌入，支持相似度搜索 |
| 嵌入模型 | EmbeddingModel (OpenAI/Ollama) | 将文本转换为向量 |
| 对话模型 | OpenAiChatModel / Ollama | 流式生成回答 |
| 文档解析 | Apache Tika / PDFBox | 解析多格式文档为纯文本 |
| 文档分割 | DocumentSplitters.recursive | 递归分割文档（500字/段，100字重叠） |
| 对话记忆 | ChatMemoryStore (Redis) | 存储多轮对话上下文 |

#### 3.2.3 RAG流程
```
用户消息 → 向量检索(相似度搜索相关文档片段) → 构建Prompt(系统指令+检索内容+用户消息) → LLM流式生成 → 速率控制 → SSE推送给前端
```

#### 3.2.4 速率控制策略
| 策略 | 说明 |
|------|------|
| 基础延迟 | 每个chunk之间最小间隔，防止刷屏 |
| 自适应延迟 | 根据chunk长度动态调整延迟 (长内容→更慢) |
| 平滑传输 | 滑动窗口处理，避免突发性大量输出 |
| 背压控制 | onBackpressureBuffer 防止生产者过快 |

#### 3.2.5 API接口
| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| POST | /api/chat/stream | 登录 | 流式聊天（带速率控制+用户知识库增强） |
| POST | /api/chat/stream/local | 公开 | 快速流式聊天（无速率控制，指定模型） |
| POST | /api/shared-knowledge-base/chat/stream | 登录 | 基于共享知识库的AI问答 |

#### 3.2.6 两种知识库AI对话
| 类型 | knowledge_base_type | 向量隔离方式 |
|------|---------------------|-------------|
| 个人知识库 | 1 | knowledge_base_id = userId，只检索该用户的向量 |
| 共享知识库 | 2 | knowledge_base_id = 共享知识库ID，检索知识库内所有向量 |

### 3.3 文件管理模块

#### 3.3.1 模块概述
支持 md/txt/doc/pdf 文件上传，自动转换格式、向量化入库，实现文档的知识化管理。

#### 3.3.2 核心实体
| 表名 | 说明 | 关键字段 |
|------|------|----------|
| `t_file_info` | 文件信息表 | id, original_filename, file_name, file_extension, file_size, file_url, user_id, file_md5 |
| `documents` | 向量文档表 | embedding_id, user_id, text, metadata, embedding(vector), file_id, knowledge_base_id, knowledge_base_type |
| `t_knowledge_base_file` | 知识库文件关联表 | id, knowledge_base_id, file_id, uploader_id, source_type |

#### 3.3.3 文件处理流程
```
上传 → 类型检测(md/txt/doc/pdf)
      ├─ .md → PdfUtils.convertMarkdownToPdf (iText)
      ├─ .txt → DocumentToPdfUtils.convertTxtToPdf
      ├─ .doc → DocumentToPdfUtils.convertDocToPdf
      └─ .pdf → 直接使用
         ↓
      存储PDF文件 (X-File-Storage / 本地)
         ↓
      Apache Tika 解析PDF文本
         ↓
      DocumentSplitters.recursive(500, 100) 递归分割
         ↓
      EmbeddingModel.embed() 向量嵌入
         ↓
      存入 PgVector (knowledge_base_id + knowledge_base_type)
         ↓
      关联 t_file_info 和 t_knowledge_base_file
```

#### 3.3.4 API接口
| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| POST | /api/documents/upload | 登录 | 上传文档，自动转换+向量化 |
| POST | /api/documents/files/list | 登录 | 分页文件列表(支持排序/搜索) |
| DELETE | /api/documents/files/{id} | 登录 | 删除文件(先删向量再删文件) |
| POST | /api/documents/test-parse | 公开 | 测试文档解析功能 |

#### 3.3.5 设计要点
- 所有非PDF格式先转PDF，统一处理流程
- 文件大小限制10MB（上传层）/ 50MB（解析层）
- 删除文件时先清理向量数据库，再删文件记录
- 按 user_id 严格隔离，确保数据安全
- 支持排序字段白名单校验，防止SQL注入
